# The Decision Room

A self-contained coin-toss web app with an original two-sided collector coin, animated flips, synthesized metallic sound effects, and flip statistics.

## Run locally

Open `index.html` in any modern web browser. There are no dependencies, build steps, or server requirements.

## Deploy with GitHub Pages

1. Create a GitHub repository and add `index.html` and this `README.md`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose the `main` branch and the `/(root)` folder, then save.
5. After GitHub Pages finishes deploying, the site will be available at `https://<your-github-username>.github.io/<repository-name>/`.

The page uses relative, self-contained assets, so it can also be hosted on any static web host.

## Features

- Responsive layout for desktop and mobile
- Custom illustrated Sun and Tide coin faces
- 3D flip animation with reduced-motion support
- Procedurally generated coin sounds with a mute toggle
- Heads, tails, and total toss counters
- No third-party libraries or external assets
